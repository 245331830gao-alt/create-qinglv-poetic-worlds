# 风格深挖：青绿东方诗境

## 定位与观察边界

将这组作品命名为“青绿东方诗境”是为便于复用而建立的工作名称，不是对作者、流派或媒介的鉴定。可观察到它结合了工笔花鸟式的细密描绘、青绿山水的设色与层叠、现代插画的简化轮廓和超现实空间。部分图呈现浅体积的场景感，但不能仅凭图像判断是否用过3D。

不要将它笼统归为水墨、摄影或游戏概念图。它的辨识度来自**结构简、纹理细、色彩静、生命小、空间奇**。其中“生命小、空间奇”在人物近景和纯田园图有例外。

## 六层构成

| 层 | 可见特点 | 转译为生成规则 |
|---|---|---|
| 大形 | 岩柱、长草台、半圆树冠、缓坡、弧浪 | 先选2—3种不同方向的轮廓，不堆满山峰 |
| 空间 | 横向展开，雾中断山脚，远景像薄色剪影 | 近景精细，中景可读，远景低对比；允许画卷式空间 |
| 植被 | 极细分枝、垂直柳丝、小叶点、密集白花 | 细节形成簇与帘幕，局部密集、局部断开 |
| 生命 | 舟、马、鱼、鹤、旅人、灵兽 | 设置一个清楚的行动或陪伴关系 |
| 色光 | 灰绿青蓝统摄，少量朱橙，白色轻盈 | 用冷暖与明度差替代强烈饱和度和戏剧光 |
| 表面 | 微细纤维、绢布般颗粒、薄染哑光 | 让纹理贴合物体，避免一层噪点滤镜覆盖一切 |

## 色彩系统

以下色号与面积是重建风格的设计建议，非从原图精确采样或统计的结果。

| 用途 | 建议色 | 使用方法 |
|---|---|---|
| 天空与远水 | 灰蓝 `#B9CED8`、浅雾蓝 `#D9E4E8` | 连接大片低细节空间 |
| 雾与花、白衣 | 象牙白 `#F1F1E6` | 白中保留轻微暖灰层次 |
| 草坡与荷叶 | 青瓷绿 `#A6BA98`、鼠尾草绿 `#8FA68A` | 主色块使用两到三层变化 |
| 苔藓与深叶 | 苔绿 `#627B59`、松绿 `#29483D` | 集中在树冠、崖缘、前景 |
| 暖色锚点 | 朱橙 `#CF6742`、浅赭金 `#CAB26E` | 鱼头、衣服、花树或小太阳 |
| 线与结构 | 深青灰 `#283D37` | 船、树干、屋顶、发髻 |

一般用青绿／青蓝承担大部分画面，白与雾承担缓冲，深绿固定重心，暖色作小点。避免将比例硬套到每张图：锦鲤分支几乎全绿，海浪分支白色可占很大面积，月夜的深绿比春景更重。

## 构图真正的规律

### 1. 非对称平衡

一侧为深色、复杂的山树，另一侧为浅色、开阔的天空与水。用一艘小船、一轮月、一条鱼补偿空白侧的视觉重量。不是左右各放一棵树的机械对称。

### 2. 大轮廓和细纹理分工

远看先看到横台、岩柱、树冠或丘陵曲线；近看才看到柳丝、花点、叶脉和草线。弱化纹理时大形仍须成立。精细并不等于所有景层同样清晰。

### 3. 方向对照

横向：水面、草台、云带、船；纵向：岩柱、藤条、树干；曲线：树枝、草坡、鱼身、兽毛与浪。选一个主方向，再用另一方向支撑，不四处塞相同树形。

### 4. 尺度是叙事

02用飞鹤、小舟与高台亭树形成多级尺度；09与11用小屋和朱衣旅人标定高台；08用女子和巨型白色灵兽构成显著尺度反差。对山水分支，可将人物高度设为画面约2%—6%，作为提示建议；03、05、08中的人物更大，不能强制缩成一点。

### 5. 留白是一种有内容的空间

天空有薄色与底纹，水面有少量细波，雾带隐藏地形连接，荷塘空处让鱼的游动成立。不要生成大片没有色彩关系的纯白背景；也不要把“留白”误写成海报文字区。

## 形态与材料词库

- 山石：象牙灰崖面、纵向细纹、苔藓包顶、浅凹洞、薄草台与厚崖底、远处青蓝峰影。
- 树木：水平伞冠、苍老弯干、透明小叶、细枝网络、长柳帘、细点白花。密树冠与疏枝树同时存在。
- 草坡：长弧线、分层低对比绿、竖向细草、稀疏微花、无明显泥土或杂乱污渍。
- 建筑：白墙、深绿或青灰瓦、简洁屋脊、小庭院或亭子。允许宋画气韵，但不把现代概括建筑宣称为严格宋代建筑。
- 水：平静横线、薄倒影，或顺着浪体的密集细线。不是塑料镜面，也不要求所有场景都有倒影。
- 动物：温柔、轮廓简净，鱼鳞、毛丝和羽毛细腻；鳍尾可略通透。避免张牙舞爪与亮眼魔法特效。
- 人物：侧身、背身或远景，脸部信息克制，长袍形成稳定色块与流畅轮廓。服装可艺术化，不无端叠加盔甲、法器和繁复刺绣。

## 五分支的差异

- A：整体浅青蓝，岩柱和草台是主形，柳丝是垂直节奏。01、12是水岸，09、11是悬崖高台，02加入飞鹤与云汀。
- B：整体青绿，鱼与花叶保持较清楚边缘；10用宽阔薄染水域容纳双鱼，05用巨型荷叶与小舟建立尺度关系。不画水族箱，不强加海底气泡。
- C：柔软坡线和小花点建立舒缓节奏；04以白桦和骑行者组织道路，06以白花树和白马组织近景。现代生活元素可成立，不强制古代。
- D：03用古树、泉流与静坐人物形成围合；08让巨大白色灵兽占据横向大形。允许艺术化夸张，不指定其必须属于某个已知神话物种。
- E：07以巨浪、白色鲸形与远帆构成动势，是本组中动态更强的例外。沿用绘画线纹，避免风暴灾难片色调。

## 失败模式与修正

| 偏差 | 原因 | 修正动作 |
|---|---|---|
| 变成厚重传统水墨 | 只写国风、山水、水墨 | 加入工笔细线、薄层设色、清晰局部轮廓；移除大片泼墨 |
| 变成发亮3D游戏场景 | 堆砌仙境、史诗、电影光 | 强调哑光绘画、柔光、简化轮廓；减法器、金色与硬光 |
| 每处都花哨 | 所有元素等量细化 | 把细节压到两三处簇群，清理天空和中间水域 |
| 淡而糊 | 全局柔焦和降对比 | 恢复近景枝条、船与动物轮廓，雾只影响部分景层 |
| 绿色单调 | 全画同一绿 | 加灰蓝远景、暖白和深松绿，小面积暖色锚点 |
| 像元素拼贴 | 同时混入所有参考物 | 保留一个主分支与一个超现实规则 |
| 人物抢画面 | 套时尚肖像或近景 | 山水分支缩小人物；03型人物分支保留中景但强化古树框架 |
| 梦境变恐怖 | 巨物、雾、未知动物被恐怖化 | 写清温柔共处、明亮空气、舒展姿态与非威胁距离 |
